# Estimador de Costos 📊

Una aplicación moderna y eficiente desarrollada con **Flutter** para el cálculo y gestión de presupuestos. Este proyecto está diseñado para ofrecer una experiencia de usuario fluida y multiplataforma.

## 🚀 Características

* **Cálculo en Tiempo Real:** Estimaciones precisas procesadas instantáneamente.
* **Interfaz Adaptativa:** Diseño limpio y responsivo gracias a los widgets de Material Design.
* **Multiplataforma:** Compilado desde una sola base de código para funcionar en múltiples dispositivos.
* **Arquitectura Limpia:** Código organizado siguiendo las mejores prácticas de Dart y Flutter.

## 🛠️ Tecnologías Utilizadas

* [Flutter](https://flutter.dev/) - Framework de UI para desarrollo multiplataforma.
* [Dart](https://dart.dev/) - Lenguaje de programación optimizado para aplicaciones de cliente.
* **Windsurf Editor** - Desarrollo asistido por IA (Cascade) para un código más robusto.

## 📦 Instalación y Configuración

Si deseas ejecutar este proyecto localmente, asegúrate de tener configurado el entorno de Flutter.

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/TU_USUARIO/estimador_costos.git](https://github.com/TU_USUARIO/estimador_costos.git)
    ```
2.  **Entrar al directorio:**
    ```bash
    cd estimador_costos
    ```
3.  **Obtener las dependencias:**
    ```bash
    flutter pub get
    ```
4.  **Ejecutar la aplicación:**
    ```bash
    flutter run
    ```
